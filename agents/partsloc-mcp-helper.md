# PartsLoc helper for AI assistants (local, read-only)

A small program that lets an assistant (Claude Desktop, Claude Code, or any app that supports MCP stdio servers) answer questions from a **copy of a PartsLoc backup** the person has put on their computer: "do I have this part, and where?", "what is low?", "make labels for shelf B3", "turn this list into an import file".

- **Local and read-only.** It reads one backup file. The only things it writes are new label PDFs and import CSVs, never over an existing file, never the backup.
- **No network.** No account, no server, no background process. It starts when the assistant uses it and exits with it. Installing it downloads Python and one or two small packages once; using it never goes online.
- **Same answers as the app.** The Yes / Probably / No verdict, its wording and its reasons are a port of the app's own answer logic, so the phone and the assistant agree. Every reply says how old the copy is, because the phone may have moved on.
- **Free and a gift.** Use it, share it, change it.

## How an assistant installs it with a person

Follow [partsloc-mcp/INSTALL.md](partsloc-mcp/INSTALL.md): Python, the helper, copying the backup from the phone (Settings, Data, Full backup), registering it in Claude Desktop or any other MCP client, and uninstalling.

Files: [partsloc_mcp.py](partsloc-mcp/partsloc_mcp.py), [check_import.py](partsloc-mcp/check_import.py) (the same checker described in [import-format.md](import-format.md); the helper imports it rather than copying its rules), [requirements.txt](partsloc-mcp/requirements.txt).

## Tools

- `find_part(query)`: Yes / Probably / No with the count, shelf and reasons.
- `where_is(part)`: every place holding it, with counts.
- `list_place(place)`: what is in a shelf, bin, room or truck.
- `low_stock()`: LOW and OUT parts, with ideal level and supplier.
- `labels_for(parts, place)`: a PDF on US Letter, Avery 5160 layout, with QR codes the app scans (QR drawing needs the optional `segno` package; without it the helper says the sheet has no codes).
- `make_import_file(rows)`: a CSV for Settings, Data, Import parts from CSV, written only if the checker finds no errors.

## Rules for the assistant

- A copy is not the shelf. Quote the age of the copy, and do not turn a Probably into a Yes.
- Do not ask for or send the backup anywhere. It contains the person's parts list and who counted what.
- The CSV export (Settings, Data, Export inventory CSV) also works but holds parts only, so every answer from it is Probably or No.
