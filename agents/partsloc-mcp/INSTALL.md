# Install the PartsLoc helper (for an AI assistant to follow WITH the person)

**What this is.** A tiny program that lets you ask an AI assistant things like "do I have a LMB24 actuator, and where?" using a copy of your PartsLoc backup. It only **reads** a file on your computer. It starts when the assistant needs it and stops when the assistant stops. It never connects to the internet, has no account, and does not run in the background.

**What it is not.** It is not the phone app and not a live view. It sees the copy you give it, so it can be out of date. Every answer says how old the copy is.

## For the assistant: how to run this install

Go one step at a time, say what each step does in plain words, and wait for the person to confirm before moving on. Do not ask them to type commands you have not explained. If a step fails, stop and read the error to them; do not guess. Offer to skip the optional parts.

Before you start, tell them: the backup holds their parts list (names, counts, places, who counted). It stays on their computer; this helper sends it nowhere. The only network use in the whole process is *downloading* Python and two small packages once (steps 1 and 3), and sending the backup from the phone to the computer (step 4), which uses the phone's data unless they are on Wi-Fi. Suggest Wi-Fi.

### Step 1. Python 3.10 or newer

Ask them to open a terminal (Windows: press the Windows key, type `cmd`, Enter. Mac: Terminal app) and run `python --version` (Mac may need `python3 --version`).

- If it prints 3.10 or higher, go to step 2.
- If not found or older: Windows: install from python.org/downloads, and **tick "Add python.exe to PATH"** on the first screen. Mac: python.org/downloads, or `brew install python` if they already use Homebrew. Linux: their package manager (`sudo apt install python3 python3-venv`).
- Close and reopen the terminal, then check the version again.

### Step 2. Put the helper in a folder

Make one folder they will remember, for example `PartsLoc` in their home folder, with a `helper` folder inside it. Download these files into `PartsLoc/helper`:

- `partsloc_mcp.py`
- `check_import.py` (the same checker the site offers; the helper uses it so import files follow the app's rules)
- `requirements.txt`

They are all in the `partsloc-mcp` folder next to this file on the PartsLoc site (`agents/partsloc-mcp/`). If the person was given the whole folder by a friend, use that instead.

### Step 3. Install what it needs, in its own private space

A private "virtual environment" keeps this from touching anything else on the computer and avoids the "externally managed environment" error that newer Macs and Linux machines show.

In the terminal, move into the helper folder (`cd` followed by its path), then:

```
python -m venv venv
```

then install (Windows):

```
venv\Scripts\python -m pip install -r requirements.txt segno
```

or Mac / Linux:

```
venv/bin/python -m pip install -r requirements.txt segno
```

`segno` is optional. It draws the QR codes on label sheets. Leave it off and everything else works, and label sheets will warn that they have no QR codes.

(Use `python3` instead of `python` on a Mac if `python` is not found.)

### Step 4. Copy the backup from the phone

On the phone, in PartsLoc:

1. Tap **Settings** (bottom of the screen).
2. Scroll down to **Data**.
3. Tap **Full backup (JSON)**. Android opens its share sheet; the file is called `partsloc-backup-` plus today's date and `.json`.
4. Send it to the computer by whatever the share sheet offers that the person already uses: email it to themselves, **Save to Drive** (then download it on the computer), or **Quick Share** to a nearby Windows or Chromebook computer. Wi-Fi is better than mobile data for this.
5. On the computer, save or move the file into the `PartsLoc` folder (the one that contains `helper`, not inside `helper`).

Do **not** use "Export inventory CSV" for this unless the backup is not possible: the CSV has only the parts list, with no shelves or count dates, so the helper can only ever answer "Probably" from it. It will still work, and says so.

To refresh later: make a new backup the same way and drop it in the same folder. The helper always uses the newest `partsloc-backup-*.json` in the folder, and there is nothing to restart or reconfigure.

### Step 5. Check it by hand

From the helper folder, one line (Windows; Mac/Linux use `venv/bin/python`), with the real path to their PartsLoc folder:

```
venv\Scripts\python partsloc_mcp.py --check --backup C:\Users\NAME\PartsLoc
```

It should print `OK:` with the file name and how many parts and places it found. If it prints `Problem:`, read that to the person: usually the backup is not in that folder.

### Step 6. Tell the assistant app about it

Find the full path to the python inside `venv` (the one from step 3) and to `partsloc_mcp.py`. Use full paths: assistant apps do not start in your folder and often do not see your terminal's settings.

**Claude Desktop.** Open its settings file: in Claude Desktop choose Settings, Developer, Edit Config, which opens `claude_desktop_config.json`. (Windows: `%APPDATA%\Claude\`; Mac: `~/Library/Application Support/Claude/`.) If the file already has an `"mcpServers"` section, add the `"partsloc"` entry inside it, with a comma after the entry before it. Otherwise the whole file can be:

```json
{
  "mcpServers": {
    "partsloc": {
      "command": "C:\\Users\\NAME\\PartsLoc\\helper\\venv\\Scripts\\python.exe",
      "args": [
        "C:\\Users\\NAME\\PartsLoc\\helper\\partsloc_mcp.py",
        "--backup",
        "C:\\Users\\NAME\\PartsLoc"
      ]
    }
  }
}
```

On a Mac, the paths look like `/Users/NAME/PartsLoc/helper/venv/bin/python`. In JSON, a Windows backslash is written twice (`\\`). Save, then **fully quit and reopen** Claude Desktop (closing the window is not enough; use the tray or menu-bar icon). A small tools indicator should then list `partsloc`.

**Any other assistant app that supports MCP "stdio" servers** (Claude Code, Cursor, Cline, and others). They all ask for the same three things: a *command*, its *arguments*, and a name. Give them:

- name: `partsloc`
- command: the same venv python path as above
- arguments: `partsloc_mcp.py` path, `--backup`, and the `PartsLoc` folder path

Many take the same `"mcpServers"` JSON block shown above. For Claude Code from a terminal, one line does it (Mac/Linux shown):

```
claude mcp add partsloc -- /Users/NAME/PartsLoc/helper/venv/bin/python /Users/NAME/PartsLoc/helper/partsloc_mcp.py --backup /Users/NAME/PartsLoc
```

### Step 7. Try it

Ask the assistant: "Use partsloc: what is low on stock?" then "Do I have <a part you know is in there>, and where?" Compare the answer with the phone. If they differ, the phone is right; say so and suggest a fresh backup.

If the assistant can't see the tools: the config file has a typo (a missing comma is the usual one), a path is wrong, or the app was not fully restarted. Re-run step 5 to prove the helper works, then fix the config.

## What it can do

| Ask for | Tool | You get |
|---|---|---|
| "Do I have X?" | `find_part` | The app's own **Yes / Probably / No**, the count, the shelf, and the reasons in words |
| "Where is X?" | `where_is` | Every place that holds it, with counts |
| "What's on shelf B3?" | `list_place` | Parts in that place and the places inside it |
| "What do I need to order?" | `low_stock` | Parts that are LOW or OUT, with ideal level and supplier |
| "Make labels for shelf B3" | `labels_for` | A new PDF, US Letter, Avery 5160 layout, QR codes the app scans |
| "Make an import file from this list" | `make_import_file` | A new CSV, checked with the same rules as the app's importer |

It only ever **creates new files** (a label PDF, an import CSV), by default next to the backup, and refuses to overwrite one. It never changes the backup. Print label sheets at 100% / "actual size", not "fit to page".

## Uninstall (leaves nothing behind)

1. Remove the `"partsloc"` entry from the assistant app's config (Claude Desktop: Settings, Developer, Edit Config; delete the block, and the comma before or after it so the JSON stays valid). For Claude Code: `claude mcp remove partsloc`. Restart the app.
2. Delete the `helper` folder. That removes the program, its private Python packages and nothing else.
3. Delete any backup copies in the `PartsLoc` folder you no longer want. They hold your parts list; email attachments and Drive copies from step 4 are separate and also worth deleting.
4. Python itself can stay or be uninstalled from the system's usual place (Windows: Settings, Apps).

Nothing else was installed: no service, no startup entry, no scheduled task, no setting changed on the phone.
